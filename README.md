# NYC Yellow Taxi Dashboard

## Project Overview

This project explores New York City Yellow Taxi trip data using Power BI. The objective is to analyze travel patterns, trip distances, fares, and passenger behavior through interactive dashboards.

## Objectives

* Analyze taxi trip activity.
* Explore travel demand patterns.
* Visualize operational KPIs.
* Create an interactive dashboard for decision-making.

## Tools & Technologies

* Power BI
* Power Query
* DAX

## Data Preparation

Data was prepared using Power Query, including:

* Data cleaning
* Data type corrections
* Transformation of date and time fields
* Creation of calculated columns

## Dashboard Features

* Total trips
* Total revenue
* Average fare amount
* Passenger trends
* Peak travel periods
* Trip distance analysis

## Key Insights

* Peak demand occurred during specific hours of the day.
* Certain pickup locations generated significantly higher activity.
* Longer trips contributed disproportionately to revenue.
* Passenger volume varied considerably by day of the week.
